这是一篇排版示例。正式写作时，可以把这些内容替换成自己的文字。

## 先用文字说清楚

一篇好笔记不一定很长。一个问题、一段过程、一个小小的结论，就足够构成一次有用的记录。

Markdown 支持 **重点强调**、*简短注释*、列表和代码：

```js
const thought = '今天发现了一件有意思的事';
console.log(thought);
```

## 让图片与短片补充细节

照片适合留下一个瞬间，短片适合展示一个过程。可以在正文中插入图片和 HTML 视频播放器，让它们和文字一起讲述。

视频默认不自动播放，读者可以自己决定什么时候开始观看。

## 留下下一步

1. 今天观察到了什么？
2. 哪些方法值得再次尝试？
3. 下次还想弄明白什么？

比起一次写得很多，更期待下一次继续记录。
